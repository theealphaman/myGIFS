# Nelson Mandela Speechless Meme

**“I don't know if I paralyzed you.”** A cartoon reaction inspired by Nelson Mandela's conversation with Ted Koppel during ABC Nightline on 21 June 1990.

**Meme concept: [@theeALPHAMAN on X](https://x.com/theeALPHAMAN)**

This public project is for a shareable, remixable Nelson Mandela reaction GIF about moments when someone is stunned, speechless, silent after a question or unable to answer.

## Context

Mandela's line “I don't know if I paralyzed you” comes from the 1990 interview. The cartoon Koppel response “No, no, no, no, no!” is fictional dialogue for humour. The image is a modern illustration and should not be confused with archival footage or an endorsement from either person.
